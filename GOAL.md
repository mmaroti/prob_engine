# A trainable joint distribution with exact differentiable queries

Learn one normalized multivariate law from samples, from supplied values of any of its four query types, or from a mixture of those signals. Each query must support training the shared model on its own. Given that law, a caller should be able to ask for a density, a cumulative probability, a marginal, or a conditional on any choice of coordinates. For example, after fitting five variables, ask for the distribution of variables 2 and 5 given variable 3, integrating out 1 and 4. Then reverse the roles without retraining. Exactness concerns the answer under the fitted law. How well that law approximates the data generator is a separate, measurable question.

Use **2–5 observed dimensions** to compare every query against independent ground truth. The architectural ambition is **hundreds of variables**. Exploit learned structure where the data admit it. An unrestricted table on 100 ten-valued variables has effectively as many free masses as cells. Any compact family must say which dependencies become expensive, and show what happens when ranks, widths, or mixture sizes are capped.

## One query contract

Give each coordinate one of three roles. For disjoint index sets D and C, define Q(D,C) by taking the joint density at the D values, integrating each C coordinate up to its threshold, and integrating every remaining coordinate over its whole domain. Use counting measure on ordered discrete axes and Lebesgue measure on continuous axes. Coordinate order in the request determines value order. A batch of queries returns a batch of scalars.

| Request | Answer from the same parameters |
| --- | --- |
| Joint density or mass at x | Q(all, ∅) |
| Joint lower-orthant CDF at x | Q(∅, all) |
| Marginal density and CDF on A | Q(A, ∅) and Q(∅, A) |
| Conditional density on A given B=b | Q(A∪B, ∅) / Q(B, ∅) |
| Conditional CDF on A given B=b | Q(B, A) / Q(B, ∅) |

A, B, and the omitted coordinates may all be nonempty. Conditioning on a continuous value uses a density ratio, even though the singleton has zero probability. At zero marginal density or mass return an explicit undefined status. Preserve small positive evidence without adding epsilon to the law. Specify the reference measure and endpoint convention. The core continuous cases have ordinary densities. A deterministic copy of a real variable gives a singular law and needs a different contract.

Core queries should be deterministic finite expressions in model parameters, up to floating-point and standard differentiable special-function evaluation. Numerical integration and Monte Carlo are useful external oracles or separate approximate entries. Require parameter gradients and continuous query/evidence gradients wherever the represented function is differentiable. A histogram has zero spatial density gradient inside cells and jumps at boundaries. Discrete labels have no spatial derivative. A smooth-model entry should also show gradients away from grid-like discontinuities.

## Training through any query

Use the same query implementation during fitting and inference. A training record specifies the query type, target coordinates, evidence coordinates and values when applicable, and the observed outcome or supplied query value. Integrate omitted axes out of the model. An optimizer must be able to update the shared parameters from any one row of the table below, including when no full observation or joint-density label is available.

| Training signal | Loss from observed outcomes | Loss from supplied query values |
| --- | --- | --- |
| Joint density or mass | Minimize −log p(x) on complete draws. | At supplied points x, regress p(x) to the labeled density or mass using squared error. |
| Joint CDF | Choose a threshold vector t independently of the draw x. Minimize (F(t) − 1[x≤t])², where the event requires every coordinate to satisfy its threshold. | Regress F(t) to labeled lower-orthant probabilities. |
| Marginal | With only x_A observed, minimize −log p_A(x_A). For a marginal CDF, use the squared event loss on A. Each record may select a different subset A. | Regress the requested marginal density, mass or CDF on A to its label. |
| Conditional | With paired target and evidence (x_A,b), minimize −log p(x_A given b). For a conditional CDF, score F(t_A given b) against 1[x_A≤t_A] with thresholds chosen independently of the target given b. | Regress the conditional density, mass or CDF at the supplied evidence and query point to its label. Differentiate through both the numerator and evidence denominator. |

For all value-labeled runs, use mean squared error in the supplied units as the baseline, including at labeled zeros. Conditional labels require positive evidence under the target law. Initialize with support covering the training evidence and record any model-undefined query as a fit failure. For mixed supervision, average each active loss over its own records, then sum with declared weights. Setting one weight to one and all others to zero gives each standalone experiment.

**Training gate.** Use the two-by-two table below as a teacher and initialize a student with strictly positive, unequal masses that disagree with its labels. On fresh copies of that initialization, fit separately to joint masses, joint CDFs, proper-subset marginals, and point-evidence conditionals. Exercise both the mass and cumulative forms for the last two. For each run expose only the chosen labels, check the loss gradient against finite differences at initialization, and verify that optimization reduces the error on the supervised queries while normalization and query identities continue to hold. Also fit one joint model from a marginal and a conditional together. On this fixture, p(Y) and p(X given Y) for both Y values determine all four joint masses by multiplication, giving a direct test of how the two signals combine.

**What the observations identify.** Knowing both univariate marginals leaves their dependence undetermined. Knowing p(X given Y) in one direction leaves p(Y) undetermined. In those experiments rank accuracy on the supplied query family at held-out points or on fresh outcomes. Report performance on the other queries as a transfer diagnostic. Score joint recovery when the supervision identifies the joint, as in the combined table experiment.

## The dense oracle and its compression

Let T be a nonnegative mass tensor with sum one. For ten bins on each of n axes it has 10ⁿ entries. Associate each axis with a vector v indexed by bin. The answer is a single sum over cell indices of T times the product of the selected vector entries.

| Axis role | Ordered categorical bin j | Uniform continuous cell [lⱼ,rⱼ) of width hⱼ |
| --- | --- | --- |
| Fixed value x | 1 if j=x, else 0 | 1/hⱼ inside the cell, else 0 |
| Threshold t | 1 if j≤t, else 0 | clamp((t−lⱼ)/hⱼ, 0, 1) |
| Integrated out | 1 | 1 |

This computes fractional cells at arbitrary real thresholds. Subtract two threshold vectors for an interval. For a hand check, use masses [[0.1,0.2],[0.3,0.4]] with unit-width cells on [0,2)², indexed by x then y. At (0.5,1.5) the density is 0.2, the CDF is 0.10, the y density is 0.6, and P(X≤0.5 | Y=1.5) is 1/6. Tests should also rescale one axis to catch missing inverse widths.

**Factor tables.** Replace T(i) by a product of nonnegative local potentials divided by Z, the contraction with every axis integrated out. Attach exactly one query vector per observed variable, even if it occurs in several factors. The historical triangle gives the numerator Σᵢⱼₖ Aᵢⱼ Bⱼₖ Cₖᵢ v₁(i)v₂(j)v₃(k). Z is the same sum with all v=1. Binary indicator tables encode allowed tuples. Multiplication enforces shared-variable consistency, and summing hidden indices counts weighted extensions of an observed tuple. This makes the connection to relational joins and projection explicit. Require Z>0. Eliminate indices as soon as possible. For bounded arity and K states, a tree permits O(nK²) message passing, and an elimination order of induced width w typically costs O(nK^(w+1)) for O(n) factors. A sparse graph can still have large induced width. A maximum-mutual-information spanning tree learned from samples is a concrete baseline. Extend with learned small cliques or mixtures of trees, and measure the cost of selecting the structure. [Tensor variable elimination](https://arxiv.org/abs/1902.03210)

**Mixtures of products, tensors and circuits.** Start with K latent components of weights π and normalized scalar leaves. For each component multiply the requested scalar PDFs, CDFs, and ones, then sum with π. This gives all queries in O(nK) and a sample-likelihood training objective. A full grid is recovered by allocating one product of uniform leaves per occupied cell. Try smooth scalar leaves for continuous work. Hierarchical nonnegative tensor decompositions share components across variable groups. MDMA is a particularly close published baseline, with scalar neural CDFs and a learned hierarchical tensor parameterization. Smooth, decomposable probabilistic circuits give another construction. Each sum mixes normalized children on the same coordinates, each product combines disjoint coordinates, and the query substitutions propagate to the root. With tractable leaves, one evaluation is linear in circuit edges plus leaf cost. Test learned groupings against a random fixed grouping at the same parameter budget. [MDMA paper](https://arxiv.org/abs/2106.04741) · [Authors’ PyTorch implementation](https://github.com/dargilboa/mdma) · [Einsum Networks](https://proceedings.mlr.press/v119/peharz20a.html)

**CDF networks and repeated differentiation.** For an absolutely continuous law, fill omitted coordinates with their upper limits and differentiate a valid joint CDF once in each fixed coordinate to recover Q almost everywhere. Likelihood training then differentiates this result with respect to parameters. Measure the memory and time of that backward pass. Coordinatewise monotonicity and corner normalization alone admit negative rectangle masses. The relevant criterion is *n-increasing*: every n-dimensional box has a nonnegative alternating corner sum. In two dimensions this is the rectangle form of supermodularity. In higher dimensions pairwise checks are insufficient. Grounding on every lower face, the upper limit one, and right continuity also matter. A valid CDF can contain singular mass that ordinary pointwise mixed derivatives miss. [Neural Likelihoods via Cumulative Distribution Functions](https://arxiv.org/abs/1811.00974)

A counterexample applies directly to stacked bivariate grid layers. On the unit square let each inner output be u=xy, the independent uniform CDF. Let the outer CDF be G(s,t)=min(2s,1)t, also a valid grid law. The composition H=min(2xy,1)xy assigns the square (0.70,0.72]² mass 0.5184−2·0.504+0.4802=−0.0094. All three layers can be represented exactly by grids. Any proposed closure under composition must rule out this example. Local derivative checks away from the kink can miss it.

**Sequential generators.** A Pyro-style program is a source of training targets. Even when its full observed density factors into elementary conditionals, a reversed conditional or a projection hiding a parent can require difficult integration. A general autoregressive network or invertible flow is a useful fitted likelihood baseline. To qualify for the exact track it must exhibit the computation for every mask. A finite latent chain with enumerated states supplies an independent exact oracle. [Pyro hidden Markov model examples](https://pyro.ai/examples/hmm.html)

## Correctness gates before fitting

Evaluate at known settings and at randomly initialized and trained parameters. Use independent scalar enumeration or analytic formulas for small cases. A model restricted to a family can pass mathematical validity even when it fits a particular target poorly.

1. **Mass and support.** Check Q(∅,∅)=1, nonnegative density/mass, zero CDF on any lower infinite face, unit upper limit, coordinatewise monotonicity, and nonnegative rectangle masses. Check additivity after bisecting a rectangle. For discrete laws enumerate atoms and reconstruct every mass by differencing the CDF. For continuous small grids test all cell corners plus random off-grid rectangles, endpoints and outside points. Integrate density independently on a small smooth fixture.
2. **Marginal and conditional coherence.** For n≤5 enumerate the three roles (fixed, threshold, omitted) for each coordinate. Check direct and staged elimination, all axes kept/dropped, noncontiguous masks, reversed conditioning, and a target/evidence/omitted split. Check conditional normalization, the joint/marginal ratio against an independent oracle, and recovery of a marginal by integrating the conditional against the evidence law. Test zero cells, impossible evidence, and tiny positive evidence.
3. **Gradients and shape.** At smooth interior points compare AD with central differences in a query value, an evidence value, and a parameter of each query type. For a smooth fixture compare mixed derivatives in different orders with the density. Perturb conditional denominators as well as numerators. Test a batched call against its scalar loop and permute coordinate labels together with data and masks. Use an explicit sided convention at histogram knots.
4. **Numerics.** Use float64 references and a proposed starting tolerance of absolute 1e−8 plus relative 1e−6 for small exact identities, and 1e−5 plus 1e−3 relative for finite differences (start with step 1e−5). Report tolerance, worst residual and failing query. Compare rare positive values in log space, with structural zeros handled separately. Retry numerical integration oracles at a tighter tolerance. Validity checks accompany a construction or argument that the law is normalized and nonnegative for all admissible parameters.

## Learning fixtures and independent answers

In sample-based runs give learners the observed coordinates needed by the selected objective, variable types, and declared supports. In value-labeled runs give them the requested points, masks, evidence, and training labels for the selected query types. Hold back program traces, latent labels, graph, generator order, source images, and evaluation labels in both settings. Here a projection selects any subset of observed coordinates, including non-prefix subsets. For each sequential fixture run both a full-observation fit and a **new fit on projected data only**. Separately query projections of the full fit. These test different abilities.

| Fixture (observed dimension) | Generator, oracle and discriminating question |
| --- | --- |
| Dense and independent controls (2–5) | Draw positive ten-bin cell weights from independent unit exponentials and normalize. Repeat with factorized univariate weights and with structural zeros. Use enumeration and the fractional-cell rule above. Compare learning curves against a sample-count histogram. Random dense five-axis weights deliberately expose sparse-data limits. |
| Hidden fork and hidden chain (2–5) | Draw a fair binary parent and three children that independently copy it with probability 0.9. Hide the parent, or one child, and predict one sibling from the others. For a five-site Markov chain use a fair initial bit and copy probability 0.85. Hide alternating sites. Sum the complete joint over omitted bits for every oracle. Randomly permute observed columns. |
| Collider and higher-order interaction (2–5) | Draw independent fair bits X,Y, then Z=X XOR Y with a 0.05 flip probability. Every pair is independent, yet P(X=Y given Z=0)=0.95. Include the noiseless case for structural zeros, and a five-bit noisy parity law with four fair inputs. Enumerate bit strings. Jitter each bit uniformly within its own bin for a continuous counterpart. A pairwise tree can fit every pair and still miss this signal. |
| Smooth sequential law and its projections (2–5) | Draw X₁ standard normal, then Xⱼ=0.8 Xⱼ₋₁+0.6 εⱼ with independent standard-normal noise. Covariance is 0.8 to the power of the index distance. Use covariance submatrices and Gaussian conditioning for analytic densities, and independent high-accuracy normal rectangle integration for CDF references with recorded numerical error. Drop internal coordinates and condition on both endpoints. |
| Nonlinear sequential law (2–3) | Draw X uniformly on [−1,1], then Y=X²+ε with Gaussian noise of standard deviation 0.1. Optionally draw an independent second noisy reading of X². Integrate the product of the elementary conditional PDFs/CDFs against the uniform parent by one-dimensional adaptive quadrature, splitting at any X threshold. Hide X and predict one reading from the other. With X as target, the reverse conditional can be bimodal. |
| Unordered pair factors and geometric support (2–5) | Make a four-cycle of binary factors, each weight 3 for equality and 1 otherwise. Enumerate and normalize the 16 states. Hide opposite vertices. Separately use a uniform planar annulus with radii 0.4 and 1, independent of any added uniform axes. Its density is constant on the ring. Compute interval slices by subtracting inner-disk chords from outer-disk chords, then integrate slice lengths for rectangle/CDF answers. Test the hole and both conditional lobes. |
| Historical image (2, diagnostic) | Normalize the grayscale pixel weights of the experimental branch’s hand-drawn image, then sample with uniform within-pixel jitter. Use prefix sums and fractional boundary cells for truth. Report thin-feature and empty-region errors alongside global CDF error. Directly fitting the image or its CDF is a separately labeled supervised run. [Image fixture](https://github.com/mmaroti/prob_engine/blob/024197c/src/prob_engine/images/handdrawn.png) |

Every finite joint admits a chain-rule description. The discovery challenge is to infer useful dependencies from samples across different orderings, projections, and interaction orders. Score observable predictions. A hidden graph need not be identifiable from the observed law.

## Comparing submissions

The following is a proposed common protocol. Freeze generator code, datasets, masks, and query files once before comparing implementations. The historical plotting scripts do not implement this benchmark.

- **Shared runs.** Use dataset seeds 11, 23, 47 with one fixed random column permutation per dataset. Share 2,000 and 20,000 nested training rows, 2,000 validation rows and 10,000 independent test rows per fixture. Reserve an unseen generator seed/permutation for the final run. Select hyperparameters using validation data of the same supervision type. Give entrants the same hardware, one CPU or GPU allocation, 30 minutes per fit including structure search, and 8 GiB of model working memory. Publish hardware, dtype, dependencies, tuning trials and stopping rule. For value-labeled runs use the same record budgets with frozen query designs and separate validation and test records. Generate query locations independently of target draws when their locations could reveal withheld density information. In mixed runs split the fixed training budget among active signals and publish the split.
- **Queries.** Freeze 256 test rows per role pattern through n=5. Use their coordinates as density points, evidence and one set of thresholds. Also test thresholds at independently combined marginal quantiles 0.01, 0.1, 0.5, 0.9 and 0.99 and boxes crossing support boundaries. Use every disjoint target/evidence assignment for conditional tests. Stratify impossible and bottom-1%-positive evidence separately. Keep their counts and worst errors visible.
- **Primary ranking.** First require all four query classes and the correctness gates. Compare entries within the same supervision type, masks and budget. For partially identifying supervision use the supervised-family ranking above. For joint recovery, within each fixture rank eligible entries by (1) mean held-out joint negative log likelihood per observed dimension, (2) joint CDF mean absolute error, (3) mean absolute marginal log-density error and marginal CDF error, and (4) the analogous conditional errors. Compare logs on positive oracle-density test draws, with a predicted zero scored as infinite error. Score exact zero targets separately in ordinary mass/density units. Average ranks of the two metrics within classes 3 and 4, then weight all four classes equally. Macro-average over masks, seeds, sample sizes and the six non-image fixture families so an easy large dataset cannot dominate. Report raw values and seed spread with the ranks. Give ties their mean rank. List timeouts, missing queries and gate failures explicitly outside the eligible ranking.
- **Scaling to 100 and 256 variables.** Use the same model code and sample-only input on a permuted binary copy tree (each new node chooses a uniform earlier parent and copies it with probability 0.85) and on a smooth latent mixture (a fair hidden sign, independent unit-variance Gaussian leaves with means equal to that sign). Exact evaluator references are tree messages and a sum of two products. Run n=5, 20, 100, 256 with the larger training budget above. At each size freeze 256 queries per class, mixing singleton, half-observed and nearly full masks, plus reverse conditionals and omitted axes. Include marginal orthants with one finite threshold, and near-upper-tail thresholds for full orthants. Report log probabilities as well as absolute errors so underflow cannot earn a perfect CDF score. Use the same correctness identities on sampled masks. Record parameter count, largest contraction intermediate, peak memory, fit time, batch-1 and batch-256 query and backward latency after warm-up. Include compilation and cache costs separately. Report the largest size completing all four query classes within 8 GiB and 60 seconds per query batch including backward. Publish a separate scale ranking by largest completed size, then the four-class accuracy ranking at that size. Dense small-instance reference methods remain valuable regardless of scaling eligibility.

Independent work can start from the enumerative oracle and gate suite, a learned factor graph, an MDMA or circuit baseline, and a constrained CDF network. Each model submission should identify its validity argument, training objective, structure selection, per-query cost, and one distribution it expects to fit poorly. A result worth reproducing includes the revision, invocation, saved configuration, raw per-fixture scores, and a failing seed or query for each observed limitation.
